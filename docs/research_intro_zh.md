# 中文研究介绍

## 基于 STAMP 的风险自适应犹豫模糊交互 TOPSIS 稳健评价方法

本研究面向复杂应急场景中的人才能力评价问题，针对能力指标缺乏系统化构建依据、专家判断存在犹豫性、评价指标之间具有非独立关系以及最终排序存在不确定性等问题，构建一种融合 STAMP 系统分析、风险自适应犹豫模糊建模、稀疏属性交互识别和稳健 TOPSIS 排序的综合评价框架。

在指标建模阶段，研究利用 STAMP 的系统控制思想，从安全约束、控制结构、控制行为和反馈机制等层面对复杂应急系统进行结构化分析，并据此形成具有系统层级关系的人才能力评价指标体系，使指标构建过程具有明确的系统逻辑基础。

在评价信息处理阶段，采用犹豫模糊元素保留专家可能给出的多个候选判断值，并引入评价单元自身的犹豫程度和决策者基础风险偏好，构建风险自适应补齐系数。由此，不同评价单元可以根据局部不确定性动态调整补齐策略，从而避免所有单元共用固定参数所带来的信息损失。

针对评价指标之间的互补、替代和冗余关系，本研究采用 2-可加模糊容量构建属性交互模型，并通过稀疏化机制控制交互结构复杂度。模型在保持目标 Shapley 重要度的同时，通过交互系数刻画不同能力维度之间的协同与信息重叠关系，从而提高综合评价结果的可解释性。

在决策阶段，将属性交互容量引入正、负理想解距离的聚合过程，并依据相对贴近度形成候选方案的名义排序。在此基础上进一步建立 Monte Carlo 不确定性传播机制，对专家评价、指标重要度、风险偏好和关联结构进行联合扰动，统计分数区间、平均排名、排名接受度和两两优胜概率，使最终结果从单一确定性排序扩展为具有概率解释的稳健排名。

最终形成的研究链路为：STAMP 指标建模、犹豫模糊信息表示、风险自适应补齐、稀疏属性交互识别、2-可加 Choquet 聚合、TOPSIS 综合评价以及稳健排名分析。研究可通过可控模拟实验和独立采集的实际案例进行验证，并结合消融实验、参数敏感性、排名稳定性、稳健性和计算规模分析系统评估方法性能。
